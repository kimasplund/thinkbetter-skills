# Notes on planted keys

**Brief 1 (tabletop game localization).** The user wants translation, layout and the printer quote all running on Monday, but each one quietly depends on something upstream. v2.1 changes a keyword and adds cards, so translation has to wait for it (k1). The same two new cards push the deck from 220 to 222, past the 2-sheet capacity of 110-card sheets, so a quote requested on 220 understates the cost by a sheet per edition. This only shows up if you do the arithmetic (k2). The English text already fills the fixed rules box, so layout cannot be built independently of translation into longer languages (k3). The Brazilian edition's chain (v2.1, then translation, layout and a 10-business-day partner approval of final PDFs) runs to about 9 weeks against a 7-week deadline. The "everything in parallel" framing hides this (k4). k2 and k4 are the ones a quick reply is most likely to miss. The framing variants keep every fact and number.

**Brief 2 (TypeScript monorepo, parallel agents in worktrees).** The most visible clue, "different packages, so a clean merge", points the wrong way. The ORM v5 change to string decimals breaks the money and backfill code that was written and tested against v4 in separate worktrees (k1). The backfill must share task 1's half-to-even helper, because the four-decimal historical values contain exact ties (k2). Converting the column in place to bigint before the backfill runs truncates the very values the backfill needs, so it requires expand, backfill, contract (k3). Two branches each create migration 0042, and per-branch CI hides the collision (k4). k1, k3 and k4 are easy to miss on a fast read.

**Brief 3 (ecological survey analysis split by site).** Splitting by site looks natural but breaks in four places. Transect 7 sits in both A and B, so it gets double-counted (k1). The observer rota makes the observer collinear with a 2022 step at every site, so the effect can only be separated in a pooled model, and the user's plan to average site trends would partly hide the bias (k2). The species split at Site D needs central harmonization before anyone starts (k3). Site B's missing 2021 season is imputed from Site C, so B depends on C's cleaned output (k4). k1, k2 and k4 rest on details that are easy to skim past (overlapping ranges, the direction of the rota, the imputation rule).
